# 行文思路审查（9/28，基于试点）

## 1. 发现的问题：阶梯对比里有信号方式的混杂

原计划的 H1b 用"听不见"（E_inaud）对比"听不懂"（C−T−），想说明模型守得住前者、守不住后者，也就是过度理解是语言门控的。但两格传达边界的方式不一样：
- E_inaud D0 的场景描述里就写着"车流声盖过了一切，Kerry 一个字也听不见"，是**自然语言**；
- C−T− D0 的"听不懂"只写在状态 JSON 的 `languages_understood` 字段里，是**结构化字段**。

而试点已经显示，同一个边界用自然语言写出来（D1），效果远好于只写在 JSON 里（D0）。所以原阶梯对比把"边界类型"和"表达方式"混在了一起。把两格都换成自然语言后再看：

| 模型 | C−T− D0（JSON） | E_inaud D0（文字） | C−T− D1（文字） | E_inaud D1（文字） |
|---|---|---|---|---|
| Gemma-4-31B | 42.9 | 0.4 | **1.2** | **0.0** |
| Qwen3.8-27B | 45.8 | 12.9 | **25.0** | **12.5** |
| Qwen3.5-9B | 76.2 | 77.9 | 70.4 | 70.8 |
| Qwen3.5-4B | 78.8 | 76.2 | 66.2 | 71.7 |
| Qwen3.5-2B | 38.8 | 68.8 | 37.9 | 73.3 |

- Gemma 的"语言门控"在表达方式对齐后消失：两种边界用文字写出来，它都守得住。
- Qwen3.8 在对齐后仍有约 12 个百分点的差距，是真正的"听见不等于听懂"。
- 小模型两种边界都守不住。

结论：原稿的第一主张"模型守得住听不见、守不住听不懂"不能照原样写，否则审稿人一指出这个混杂，主张就站不住。

## 2. 修正后的主线

**一句话**：角色扮演模型知道角色听不懂，却照样用上角色听不懂的内容；问题出在生成时不应用角色的视角，而不是不知道。

语言障碍是检验这个缺口的好场景：内容就在上下文里、角色也听见了，唯一的障碍是理解。所以"知道"和"做到"可以分开测。

| 节 | 主张 | 证据（试点已有 / 主跑补齐） |
|---|---|---|
| 5.1 现象 | 以结构化状态给出语言边界时（这正是状态驱动的 NPC 系统的做法），多数模型大量使用角色听不懂的内容 | H1：三个大模型 43% 到 76%；陪衬值与乱码对照约 0；只问"下一步怎么办"时也有 30% 到 67%；命中大多是直接当成已知使用 |
| 5.2 知道却不用 | 不是不知道：直接问，模型能说出角色听不懂；让它列出角色能理解什么，清单是干净的 | H4a：状态探针答对 100%，答对的条目上照样泄漏；M1 第一步清单泄漏 0% 到 10% |
| 5.3 怎么表达有关系 | 结构化状态几乎不起作用；一句文字声明对部分模型有效，没修好的常出现"嘴上否认、内容照用" | U 与 D0 接近；D1 下 Gemma 降到 1%、Qwen3.8 降到 25%、9B 仍有 70%；H2：Qwen3.8 有 17% 到 20% 的回复同时否认与使用 |
| 5.4 听懂和听见是不是一回事 | 表达方式对齐后再比两种边界：有的模型一视同仁，有的模型对"听不懂"明显更宽松，小模型两者都守不住 | 修正后的 H1b（见第 3 节），按模型家族报告 |
| 5.5 怎么修 | 在生成前加一步显式的视角过滤，就能补上缺口，而且不压低应当理解的内容；少样本示范只对部分模型有效 | H4b：M1 把两个大模型压到约 0，有翻译器时的使用率不降 |

这条主线比原稿更稳：
- 它不依赖"语言特殊"这一个容易被混杂击穿的点；
- "知道却不用"有两条独立证据（探针和 M1 第一步）；
- 修复方法直接从诊断里来。

语言的特殊性降为第 5.4 节的一个有条件结论，表达方式对齐后仍存在的差距才算数。

## 3. 主跑前需要改的设计（都在提示层，和下载的模型无关）

1. **加一格"只在结构化状态里写明听不见"**（E_inaud_S）：英文内容，`audible_to_X: false`，场景描述中性，不写"听不见"。它和 C−T− D0 构成"都只用结构化字段"的一对。每题加 8 个提示（A/B × 4 种追问）。
2. **H1b 改成表达方式对齐的对比**：
   - 主检验：C−T− D1 对比 E_inaud D1（都用文字）；
   - 次检验：C−T− D0 对比 E_inaud_S D0（都只用结构化字段）。
3. **H3（离线翻译器）降为探索性**。试点里差异约 0，它对主线没有贡献，放在确证族里只会增加多重比较的负担。这是看过试点后做的改动，冻结时要如实写进偏离说明。
4. **H4b 的"不压制"判据改成单侧**（之前已提）。
5. **标题**：原来想用 "Heard but Not Understood"。修正后的主线更贴近"知道却不用"，可以考虑 "Knowing but Not Applying: ..."，或者保留原标题，由第 5.4 节的结果决定。

## 4. 模型阵容和主线的关系

主线要说"当前模型普遍如此"，并按家族比较表达方式的效果（5.3、5.4），所以多家族本身是主线需要的，不随上面的修改而变。已下载的 8 个模型继续用。
