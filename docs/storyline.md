# 主实验写作主线 · 2026-09-29

当前稿以主实验为准。试点叙事原文保留在 archive/storyline-pilot-20260929.md，不能当作主结果引用。

1. **两类被声明为不可及的信息都大量进入生成。** 语言清单净越界 66.70pp，不可听标记 72.17pp，11/11 模型分别超过 10pp 门；说清楚是规则金丝雀使用和固定模型集合。
2. **如何表述边界很重要。** 文字声明降幅为 32.67pp / 25.80pp；直接不理解标记比语言清单低 21.58pp。删去“结构化状态几乎没有作用”的绝对表述。匹配标记下的 27.06pp 差异仍含英文／外语差别，不解释为内在听觉机制。
3. **正确回答状态问题不保证生成遵守。** 条件化后 68.40pp，但只有 10 个模型、30 个单元；GLM 探针全错。不能写所有模型“知道却不用”。
4. **过滤有效但并不普遍安全。** 合并相对降幅 64.68%，有用内容变化 −1.96pp，过 −5pp 门。同时保留 GLM 越界增加、Nemotron 和 Qwen3.5-9B 的大幅内容损失以及语种／角色分析的失败。清单散点只能作描述。

人工核对、词形可猜性与评分器认证未完成。这是最大的实证限制；正文、摘要、图表与交付报告都要保留 provisional 标记。当地方法锁定发生在生成后、查看主结果前，没有 OSF 预注册。次要分析事后实现与 GEE 收敛修复单列。
