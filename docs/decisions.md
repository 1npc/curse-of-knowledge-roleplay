## B. 实现偏离（冻结前确认）

1. **不装环境的替代**：
   - spaCy 词形还原改为在别名表里写全单复数和所有格；
   - pykakasi、pypinyin 改为条目自带人工读音（假名、无调拼音），标准库做 Hepburn、训令式、威妥玛转换；
   - wordfreq 的 Zipf 告警改为手写熟悉词表，只告警；
   - lingua 改为标准库启发式（CJK 占比、西语与英语功能词计数），L = 1 的回复本来就全部进人工复核；
   - MeCab/UniDic、Hunspell、Wuggy 的噪声词典核验暂缓，噪声标记为 pending，到远端或交核对人核。
2. **去回显只作用于英文匹配副本**。L = 1 的回复另建副本，只删 ≥ 6 字（ja/zh）或 ≥ 3 词（es）的逐字刺激片段，再匹配 L 语别名。附录 C 伪代码的顺序会先把 L 语形式删掉再去匹配它们，所以改了顺序。
3. **命中方式取最不带框架的句子**：一条回复里只要有一句直接使用，就记无框架；否则有含糊句记含糊式；都没有才记转述归因。
4. **H2b 的定义前后不一致，待冻结时定**：2.2 节写"无 A_explicit 且非转述归因"（含糊式也算），附录 C 写"mode == unframed"。评分器两个都输出（`unattributed_use` 与 `unframed`）。建议按 2.2 的假设原文。
5. **新增 N_unheard 标记**（"couldn't hear"），用于 E_inaud 格的"表现没听见"。proposal 的标记表里没有它。
6. **值集调整**：
   - 补了几个别名：毯子也指地毯，所以 blanket 加 rug；wallet 加 purse；escalera 也指梯子，所以 stairwell 加 ladder；chair 加 armchair；church 加 cathedral；warehouse 加 storeroom、storage room；
   - 删掉 parasol、passageway 两个别名。它们会让 paraguas、pasillo 在前缀规则上被拒；这两个词确实可能靠 para-、pas- 被猜出来，已在值集里标给可猜性检验；

7. **配对混淆表**：以下两对在同一语种里不作目标与陪衬配对。ja：桟橋与橋、手袋与かばん、駐車場与廃車置き場；zh：钱包与袋子、停车场与废车场。
