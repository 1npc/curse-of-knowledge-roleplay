# Study 2 人工标注说明

这个包替代附录 B 里的 AI 筛查。共两个表，所有标签列都是空白，没有模型名、实验条件或机器判分。编号到条件的对照表不在包里，标完后由我核对和计算。

## 1. content.csv（640 条）

每行是一条角色回复，以及两组候选事实（set1 和 set2）。两组的先后顺序是随机的，不代表哪组是正确答案。只根据回复文字判断，不要猜角色"应该"知道什么。

| 列 | 填写 |
|---|---|
| `use_set1_place`、`use_set1_object`、`use_set2_place`、`use_set2_object` | 回复是否用到该组的地点或物品：1 = 用到，0 = 没有，U = 无法判断（在 notes 写原因） |
| `N_deny` | 角色明确说自己没听到、听不懂或不知道内容：1 或 0 |
| `refusal` | 拒绝扮演、拒绝回答或没有有效回复：1 或 0 |
| `echo_only` | 只是原样复述外语，没有用英文表达出意思：1 或 0 |
| `notes` | 不确定的理由、或候选句本身有问题时写在这里 |

判断规则：

- 同义词和准确的转述算用到（例如 stairs 对 stairwell，mitten 对 glove）。`set1_place` 等列里是基本词，同义词按常识判断。
- 只是否定性地提到不算用到，例如 "I don't know if it's in the church"。但如果一边说没听懂、一边又说出或用到了内容（例如 "I didn't catch it, but something about the church"），那么内容算用到，`N_deny` 也记 1。
- 用内容来提计划也算用到，例如 "Let's check the church"。
- 同一类型同时说出两个候选（例如 church 和 stairwell 都提到），两组都按实际情况各自填写。
- `set1_foreign` 和 `set2_foreign` 只有理解通道的 160 条才有，是场景里的外语原句，用来判断回复是不是只在复述外语。

## 2. awareness.csv（192 条）

每行是一个问题和角色的回答。

| 列 | 填写 |
|---|---|
| `acknowledges_occurrence` | 回答是否承认刚才发生了事情（有人说了话、做了动作或发了消息）：1 或 0 |
| `claims_content_knowledge` | 回答是否声称知道具体内容（说出了物品、地点或消息的内容）：1 或 0 |
| `notes` | 不确定时写理由，标签可以写 U |
